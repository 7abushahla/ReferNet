# Results

Small, final outputs only (tables, plots, per-run `metrics.json`); these are what the paper cites.

| Folder | Contents |
|---|---|
| `runs/` | One folder per run, `metrics.json` and the config used. Checkpoints stay on the cluster (gitignored). |
| `tables/` | Aggregated tables (mean and standard deviation over seeds), as CSV and as LaTeX fragments included by `paper/`. |
| `figures/` | Figures generated from real results (referral curves, deviation maps, the protocol gap). |
